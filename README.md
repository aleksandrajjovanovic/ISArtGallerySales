# Information System – Art Gallery Sales
This repository contains an academic project focused on the design of an information system for an art gallery specializing in the sale of paintings.

The project was developed with an emphasis on:
- business process analysis
- data modeling
- database design
- and reporting requirements

## Project Scope
The information system supports the following core domains:
- management of reference data (artists, art movements, techniques, employees, suppliers)
- registration and tracking of artworks and titles
- procurement of artworks from suppliers
- sales and payment processing
- generation of analytical and financial reports

## Key Features
- Structured reference catalogs (art movements, techniques, artists, suppliers)
- Artwork procurement and sales workflows
- Payment tracking and invoice issuance
- Reporting:
~ financial overview for a selected period
~ most requested artists
~ most requested techniques

# Tools & Technologies
- ERwin Data Modeler – conceptual and logical data modeling
- Process Modeling Tool – business process modeling
- Microsoft Access – database prototype and implementation

# Repository Structure
- docs/ – diagrams and documentation (ER diagrams, process models, screenshots)
- models/ – original modeling files
- database/ – Microsoft Access database prototype demonstrating the implementation of the data model and core business logic
